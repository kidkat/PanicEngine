# PanicEngine
Physix Engine for small football mobile game written on C#

## Version
**Current Version:** 1.0.0

## Features

- **2D Physics Simulation**: Simulate rigid bodies, collisions, and forces in 2D space.
- **Collision Detection**: Supports various shapes (circles, rectangles) and collision detection.
- **Force and Torque**: Apply forces and torques to bodies for realistic movement.
- **Constraints**: Implement joints and constraints to control body interactions.
- **Performance Optimized**: Efficient algorithms for real-time physics simulations.
- **Easy Integration**: Simple API for quick integration into Unity projects.

## Installation

To use PanicEngine in your Unity project, follow these steps:

1. **Download the Package**:
   - Clone or download the repository from [GitHub](https://github.com/kidkat/PanicEngine).

2. **Add to Unity Project**:
   - Copy the `PanicEngine` folder into your Unity project's `Assets` directory.

3. **Import the Package**:
   - Open Unity and navigate to `Assets > Import Package > Custom Package`.
   - Select the `PanicEngine.unitypackage` file and import it.

4. **Usage**:
   - Attach the `PanicEngine` component to any GameObject in your scene.
   - Configure the physics settings in the inspector.
