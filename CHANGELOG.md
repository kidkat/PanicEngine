# Changelog

All notable changes to this project will be documented in this file.

## [0.0.1]
### Added
- Initial release of PanicEngine
- Physics engine core functionality
- Field management system
- Collision detection
- Added Vector2D class for 2D vector operations + Unit tests
- Added Body2D class for 2D RigidBody & physix funcionality
- Collision2D class which checks collion against wall & collision against other bodies + Unit tests
- Basic PhysixSettings added
- FieldBounds added + Unit tests
- FieldManager added as core manager for all other components
- Bodiesmanager added as manager for all bodies in the field
